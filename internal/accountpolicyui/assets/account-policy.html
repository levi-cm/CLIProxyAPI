Routing & settings

Advanced routing & reset safety
Explain every option
Collect dashboard data
Observation-only mode does not select accounts, apply resets, execute schedules or clear quota cooldowns. Idle quota discovery is approximately every five minutes, more often for active accounts or imminent expiry; provider backoff still applies. Last-known quota remains visible with stale labels. Usage statistics begin with real completions, not past traffic. Config controls this opt-in on restart.
Off / Notify
Off never redeems automatically. Notify supplies advice only. Observation runs when dashboard collection or earliest-deadline routing is enabled. Routing must be enabled before any reset automation can run.
Automatic: expiring resets
At fresh, confirmed weekly exhaustion, immediately applies the earliest eligible saved reset if it expires before the next normal weekly refresh. No queued task or near-expiry condition is needed. Later-expiring resets stay saved. If allowance remains, the expiry guard is the safety fallback.
Automatic: all saved resets
Also allows eligible non-expiring saved resets under demand and reserve rules. More permissive than expiring-only mode. Purchased reset classes remain excluded.
Round robin / Fill first / Weighted round robin
Round robin rotates eligible credentials. Fill first uses the first eligible credential until unavailable. Weighted round robin uses configured credential weights. These are fallbacks for missing deadline evidence, not permission to bypass eligibility.
Strict / Safe-boundary affinity
Strict keeps the owner. Safe-boundary affinity may migrate only replayable work between completed requests. Never transfers an active stream, live WebSocket or account-specific continuation blindly.
Account hold / Allowance reserve
A hold excludes the account from new deadline-policy routing without interrupting active work. Allowance reserve is a percentage to keep unused, unlike the saved-credit count reserve.
Freshness and eligible credits
Only fresh, account-owned ordinary-allowance evidence can authorize resets. Purchased credits, unknown IDs, missing coverage and expired credits are not automatically usable.
Display time zone / Sorting / Filters
Berlin observes seasonal offsets; GMT+2 is fixed; UTC has no offset. Presentation options never change routing, remove accounts or alter provider timestamps.
Refresh quota / Reload snapshots
Refresh quota explicitly requests provider observations. Reload snapshots and automatic activity updates read the proxy only, without repeatedly querying the provider.
Use reset / Schedule / Clear local cooldown
Use reset redeems the selected owning account's credit after confirmation. Schedule records a local redemption time before provider expiry. Clear cooldown changes proxy routing state only, not provider quota or OAuth.
